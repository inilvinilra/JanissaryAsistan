# Smart Irrigation System

## Abstract

This project aims to develop an embedded system that performs automatic irrigation
for agricultural land using soil moisture sensors. The system continuously measures
soil moisture and automatically opens the water valve when needed.

## Method

A prototype was built using moisture sensors, a microcontroller, and a water valve.
Collected data is sent to a cloud server for analysis.

## Conclusion

Testing showed a 30% reduction in water consumption.
